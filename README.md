# ADEQUATE — QURECA Quantum Computing Course

This repository contains all Jupyter/Colab notebooks I completed as part of the **ADEQUATE Program by QURECA**, an introductory course designed to provide hands-on experience in **Quantum Information Science and Quantum Programming**.

Each notebook was written and executed in **Google Colab**, focusing on fundamental concepts such as **superposition, entanglement, quantum algorithms, and measurement theory**.
